# Security Policy

## Supported versions

Security fixes are applied on the default branch (`main`). Operators should run a current `main` commit or a release tag cut from it.

## Reporting a vulnerability

Please report security vulnerabilities **privately** through [GitHub private vulnerability reporting](https://github.com/imMamdouhaboammar/Arabic-CMS/security/advisories/new) for this repository.

Do **not** open a public GitHub issue, pull request, or discussion that includes exploit details, secrets, credentials, encryption keys, or step-by-step reproduction that would make abuse easier.

### What to include

- Affected component or surface (for example public routes, admin, plugins, storage, or backup tooling)
- Impact summary
- Reproduction notes sufficient for maintainers to verify privately
- Any known workarounds

### What to expect

Reports are reviewed privately when maintainers are available. Follow-up happens in the advisory thread. This policy does not promise a fixed acknowledgement or remediation SLA.

Thank you for helping keep Arabic-CMS and its operators safe.
